# V-JEWEL – Virtual Jewellery Try-On System 💍

An AR-enabled web application that allows users to virtually try on 3D jewellery in real-time using their device camera. Built to enhance online shopping experiences and bridge the gap between physical and digital jewellery try-on.

## 🔧 Tech Stack

- **Frontend**: React.js, HTML5, CSS3
- **AR & 3D**: Three.js, WebXR API, MediaPipe Hands
- **Backend**: Node.js, Express.js
- **Database**: MongoDB

## ✨ Features

- Real-time 3D jewellery try-on using AR
- Live camera integration and hand tracking with MediaPipe
- Jewellery collection management: Upload & Showcase modules
- Seamless integration between frontend and backend via RESTful APIs
- Responsive and mobile-friendly UI

## 🚀 Getting Started

### Prerequisites
- Node.js, npm
- MongoDB (local or Atlas)
- Webcam-enabled browser (Chrome recommended)
